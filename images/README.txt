PAWS AND HOMES PET CARE AND ADOPTION - IMAGES
=============================================

This folder is reserved for the website's own image files.

Current images
--------------
The website currently uses remote placeholder photographs loaded directly
from Unsplash (images.unsplash.com). No image files are stored in this
folder, so the site works as soon as it is uploaded to GitHub Pages.

Photographs are used under the Unsplash Licence, which allows free use.
They are placeholders only: the animals shown are not real adoptable pets,
and the pet names on the website are fictional.

If a remote image cannot load (for example, when offline), the website shows
a branded background with a paw symbol and the words "Photo coming soon", so
the layout still looks complete. Every image has descriptive alt text.

Using the website in production
-------------------------------
Before using this website for a real organisation:

1. Replace every placeholder with photographs you own or are licensed to use,
   such as photographs of your own animals taken by staff or volunteers.
2. Confirm the licence terms for every image and keep a record of them.
3. Obtain permission from any person who can be identified in a photograph.
4. Save the images in this folder, for example images/bella.jpg.
5. Update each <img> element's src attribute to the relative path,
   for example src="images/bella.jpg".
6. Write accurate alt text describing each new image.

Recommended image settings
--------------------------
- Format: JPEG or WebP for photographs
- Shape: landscape, 4:3 ratio (for example 800 x 600 pixels)
- Hero image: about 1000 x 750 pixels
- File size: under 200 KB each where possible, to keep pages fast
- File names: lower case with hyphens, for example rocky-playing.jpg
